# arkanium-core — `core.arkanium.consulting`

Aplicación **interna** para el equipo humano de Arkanium. Aquí viven el CRM (leads, oportunidades, clientes, reuniones) y el mini CMS (contenido de Insights y, después, de los servicios).

**Estado:** carpeta creada. Sin código. Se construye en la fase 5 de ARK-CORE, con su contrato propio.

**Acceso:** solo usuarios internos verificados. Nunca es público.

**Depende de:** el backend modular (pipeline, tenancy) y Clerk.

**Pendiente de decidir:** cómo publica el mini CMS hacia `arkanium-web` (que es estático). Ver `arkanium-web/docs/ark-core-002-decisiones.md`.
